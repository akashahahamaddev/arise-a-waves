# ARISE/A waves

The released card waves of **ARISE/A**, an Android trading card game. Each file in
[`waves/`](waves/) lists one released wave's cards: names, stats, effects, Casual / Balanced /
Competitive profiles and lore.

- Current release: **Wave 1 · Floranette Support**
- Schedule: [CALENDAR.md](CALENDAR.md), one wave on the first of every month
- Download the game: [arise-a-releases](https://github.com/akashahahamaddev/arise-a-releases/releases/latest)
- Wiki, rules and lore: [arise-a.akashahahamad.cc](https://arise-a.akashahahamad.cc)

A wave appears here on its release day. Card lore for upcoming waves is on the wiki ahead of time;
effects are published when the wave releases.
